# 系统环境优化

适用于全新 Windows 11 工作站。本文覆盖系统软件、保守可回滚设置与 System Profile 的用法；开发工具链见 [开发环境搭建](开发环境搭建.md)。

## 前提

- 用户目录必须为纯 ASCII。`bootstrap.ps1` 在提权前检查 `USERPROFILE` 与 `USERNAME`，含中文或其他非 ASCII 字符时退出 2。
- System Profile 只包含需要管理员权限的机器级阶段与验收，不依赖工作空间。
- 不使用 WSL、Docker、Dev Container。

## System Profile

```powershell
.\bootstrap.ps1 -Profile System -DryRun
.\bootstrap.ps1 -Profile System
.\bootstrap.ps1 -Profile System -Stages Verify
```

`-Profile System` 执行 Preflight → System → Verify。`-Stages` 可单独运行某个阶段，前置阶段按依赖自动补齐；Verify 无前置阶段，单独运行时只执行验证。

退出码：0 成功；1 验收失败；2 预检错误；3 提权被拒；4 阶段执行失败。

## 保守系统设置

System 阶段修改以下设置，全部写入 manifest 供回滚：

| 设置 | 位置 | 值 |
|---|---|---|
| 长路径支持 | `HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\LongPathsEnabled` | 1 |
| 开发者模式 | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock\AllowDevelopmentWithoutDevLicense` | 1 |
| Defender 排除项 | 工作空间根、`C:\Programs`、uv 缓存、pnpm store、`.cargo`、`.gradle`、`.m2` | 默认不添加；`-EnableDevExclusions` 启用，仅添加实际存在的路径 |

不修改遥测、服务、启动项、计划任务、系统还原点或网络栈。

Defender 排除项默认关闭。指定 `-EnableDevExclusions` 后通过 `Add-MpPreference -ExclusionPath` 添加；防篡改开启导致失败时，记录告警并跳过该项。

## 验收

```powershell
.\bootstrap.ps1 -Profile System -Stages Verify
```

检查长路径与开发者模式注册表值。System Profile 不检查开发工具命令，避免在只装系统软件的新机上误报。验收结果写入 `logs/runs/<runId>/environment-report.json`。

## 回滚

```powershell
.\bootstrap.ps1 -Rollback Last
```

回滚按 manifest 逆序还原：

- 配置文件：有备份的覆盖回备份，新建的删除。
- PATH 与用户/机器环境变量：恢复本次修改前的值。
- 注册表：恢复原值；原本不存在的删除。
- Defender 排除项：只移除本次新增项。
- 已安装软件：不卸载。

包含机器级变更时回滚请求 UAC；`-NoElevate` 只还原用户级变更。

回滚前比对文件当前哈希与本次写入后的哈希。文件在运行后被修改或删除时保留现状，记为冲突并跳过该项。
