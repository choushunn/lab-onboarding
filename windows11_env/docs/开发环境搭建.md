# 开发环境搭建

适用于全新 Windows 11 工作站。入口是仓库根目录的 `bootstrap.ps1`，数据在 `data/`，本文说明搭建内容、研究方向、国内镜像、验收与回滚。系统软件与保守系统设置见 [系统环境优化](系统环境优化.md)。

## 前提

- Windows 11，PowerShell 7.4 或更高版本，`winget` 可用。
- `USERPROFILE` 与 `USERNAME` 必须是纯 ASCII。含中文或其他非 ASCII 字符时，入口在提权与任何写入之前退出 2，须切换到英文用户名账户后重跑。
- 机器级阶段需要管理员权限。入口在同一次 UAC 中整体重启，避免逐条提权。
- 不使用 WSL、Docker、Dev Container。

## 入口与参数

```powershell
.\bootstrap.ps1 -Profile All -DryRun
.\bootstrap.ps1 -Profile All
.\bootstrap.ps1 -Profile All -Direction image
.\bootstrap.ps1 -Profile All -Direction embedded
.\bootstrap.ps1 -Profile Dev -Stages Verify
.\bootstrap.ps1 -Rollback Last
```

| 参数 | 作用 |
|---|---|
| `-Profile Dev\|System\|All` | 选择开发环境、系统优化或两者，默认 `All` |
| `-Direction base\|image\|embedded` | 选择研究方向，默认 `base`；可用逗号合并，`base` 始终保留 |
| `-Stages` | 按名称裁剪阶段，自动补齐前置阶段 |
| `-DryRun` | 输出计划，不提权、不修改系统；缺少 `data/user.json` 时跳过 Config 阶段 |
| `-NoElevate` | 跳过机器级阶段并标记 `SkippedNoAdmin` |
| `-IncludeOptional` | 安装 LLVM、NSIS、Wireshark、微信开发者工具 |
| `-WorkspaceRoot` | 显式指定工作空间根，默认 D 盘优先、C 盘回退 |
| `-ForceConfig` | 覆盖已存在且内容不同的配置；默认只备份不覆盖 |
| `-ReinstallPackages` | 对已装包执行强制重装或重新解压 |
| `-EnableDevExclusions` | 添加 Defender 开发目录排除项；默认不添加 |
| `-SkipSkills` | 跳过 Config 阶段的 Agent Skills 同步 |
| `-UserFile` | 指定用户配置，默认 `data/user.json` |

`-DryRun` 会打印阶段计划、工作空间根、包数量与人工项，不触发 UAC。

## 研究方向

研究方向决定追加哪些包与人工项，`base` 始终参与。

| 方向 | 追加内容 |
|---|---|
| `base` | 通用基础工具、语言运行时、编辑器、镜像与 AI CLI |
| `image` | OpenCV（MSYS2 pacman）、CUDA Toolkit、Nsight Compute、Nsight Systems |
| `embedded` | ARM GNU Toolchain、OpenOCD、pyOCD、Keil MDK、STM32CubeMX/Programmer/ST-LINK Utility/CubeCLT |

条目归属写在 `data/packages.dev.json` 与 `data/manual.json` 的 `directions` 字段，方向清单在 `data/directions.json`。未声明 `directions` 的条目属于 `base`。验收阶段只检查当前方向启用的命令。

## 阶段与退出码

顺序固定为 Preflight → Base → Mirrors → Toolchain → Environment → System → Proxy → Optional → Config → Verify。

| 阶段 | 需要管理员 | 内容 |
|---|---|---|
| Preflight | 否 | ASCII 用户目录、PowerShell 版本、winget、数据校验、工作空间解析 |
| Base | 是 | 工作空间目录、通用 WinGet 基础包、MSYS2、JDK、Go、.NET、Maven、Gradle；CUDA（`image`，仅 NVIDIA GPU）、ARM GNU Toolchain（`embedded`） |
| Mirrors | 是 | pip、uv、npm、cargo、Rustup、Go、Maven、Gradle、NuGet、MSYS2 pacman |
| Toolchain | 否 | pacman 工具链、pacman 密钥环初始化、rustup、uv 二进制、corepack/pnpm、npm 全局包、PowerShell 模块、VS Code 扩展；OpenCV（`image`）、OpenOCD 与 Keil MDK（`embedded`） |
| Environment | 是 | PATH、HOME、JAVA_HOME、CUDA_PATH、PYTHONUTF8、VCPKG_ROOT、GOPATH、SSL 变量清理 |
| System | 是 | 系统软件、长路径、开发者模式、Defender 排除项 |
| Proxy | 否 | 需要代理的 CPython、uv 工具（ruff、pre-commit）与 vcpkg；pyOCD 在 `embedded`；未检测到代理时整阶段跳过 |
| Optional | 是 | 可选开发工具：LLVM、NSIS、Wireshark、微信开发者工具；全部可选，单个失败只告警 |
| Config | 否 | 全局 AGENTS.md、Git 身份、Claude Code 与 Trae MCP 配置、Windows Terminal 外观、用户配置询问；放在最后执行 |
| Verify | 否 | 命令存在性、配置与镜像、实际版本；人工项由入口汇总输出 |

退出码：0 成功；1 验收失败；2 预检错误；3 提权被拒；4 阶段执行失败。

## 工作空间

`data/bootstrap.json` 定义根目录与子目录：

```text
D:\Workspace
├─ Python
├─ Java
├─ STM32
├─ Cpp
├─ Web
├─ Go
├─ Rust
└─ Docs
```

D 盘不存在时使用 `C:\Workspace`。`-WorkspaceRoot` 优先于自动选择。实际根目录写入 `logs/runs/<runId>/summary.json`。

## MSYS2 与 C/C++

MSYS2 从清华 TUNA 安装器安装到 `C:\Programs\msys64`，阿里云为备用源。随后通过 pacman 安装：

```text
mingw-w64-ucrt-x86_64-make
mingw-w64-ucrt-x86_64-gcc
mingw-w64-ucrt-x86_64-gdb
mingw-w64-ucrt-x86_64-clang
mingw-w64-ucrt-x86_64-clang-tools-extra
mingw-w64-ucrt-x86_64-ccache
mingw-w64-ucrt-x86_64-openocd
mingw-w64-ucrt-x86_64-python
```

验证：

```powershell
gcc --version
g++ --version
gdb --version
clangd --version
ccache --version
openocd --version
```

MSYS2 自带的 `python` 会抢占裸命令。项目内一律用 `uv run`，不在系统 Python 或 MSYS2 Python 中装包。

## Python 与 uv

uv 本体从阿里云 PyPI 下载 Windows wheel 并解压出 `uv.exe`、`uvx.exe`、`uvw.exe` 到 `%USERPROFILE%\.local\bin`，不依赖 GitHub。托管解释器按版本线安装最新补丁：

```text
3.9
3.12
3.14
```

`uv python install` 需要访问 GitHub。这些软件统一放在最后的 Proxy 阶段：入口会检查 `127.0.0.1:7890` 是否监听，未监听时跳过整个阶段并在汇总里提示，不影响其他阶段；之后运行 `scripts\proxy-on.ps1`，再执行 `just bootstrap -Stages Proxy` 补齐。

`uv tool` 安装 ruff、pre-commit、pyOCD。vcpkg 从 GitHub 克隆到 `C:\Programs\vcpkg` 后执行 `bootstrap-vcpkg.bat`，需要 Visual Studio 的 C++ 工具链；该包为可选，失败只记录告警。

## Node、Java、Go、Rust、.NET

- Node 22 由 winget 安装；`corepack enable` 后激活最新 pnpm，`pnpm store` 指向 `C:\Programs\.pnpm-store`，该盘不可用时使用 `C:\Workspace\.pnpm-store`。
- npm 全局包：`@anthropic-ai/claude-code`、`@openai/codex`、`ccswitch`、`@alibaba-group/open-code-review`、`@tauri-apps/cli`、`lv_font_conv`、`yarn`。
- JDK 21 由 winget 安装；Maven 与 Gradle 从压缩包解压到 `C:\Programs`，版本由 `data/packages.dev.json` 固定，`bin` 加入机器级 PATH。
- Go 由 winget 安装，`GOPROXY` 与 `GOSUMDB` 在 Mirrors 阶段写入。
- Rust 用 rustup-init 从清华 TUNA 下载，默认工具链 `stable-x86_64-pc-windows-msvc`。
- .NET SDK 10 由 winget 安装。

## 嵌入式工具

ARM GNU Toolchain 从 developer.arm.com 下载压缩包解压到 `C:\Programs`，`bin` 加入机器级 PATH；openocd 由 MSYS2 pacman 安装，pyOCD 由 uv tool 安装；三者随 `embedded` 方向启用。OpenCV 由 MSYS2 pacman 安装，随 `image` 方向启用。Keil MDK 在 `embedded` 方向的 Toolchain 阶段自动下载安装包到 `installers/mdk543.exe`，已安装时按注册表名与 `UV4.exe` 路径跳过；安装程序与许可证激活仍需人工完成。

## 国内镜像

`data/mirrors.json` 是唯一真源，Mirrors 阶段写入以下位置：

| 通道 | 配置位置 | 镜像 |
|---|---|---|
| pip | `%USERPROFILE%\pip\pip.ini` | 阿里云主源、中科大 USTC 备用、timeout 60 |
| uv | `%APPDATA%\uv\uv.toml` | 阿里云 PyPI 索引，默认源 |
| npm / pnpm / yarn | `%USERPROFILE%\.npmrc` | `https://registry.npmmirror.com/` |
| corepack | 用户环境变量 | `COREPACK_NPM_REGISTRY=https://registry.npmmirror.com/` |
| cargo | `%USERPROFILE%\.cargo\config.toml` | `sparse+https://rsproxy.cn/index/` 与 `git-fetch-with-cli = true` |
| Rustup | 用户环境变量 | `RUSTUP_DIST_SERVER`、`RUSTUP_UPDATE_ROOT` 指向清华 TUNA |
| Go | `go env -w` | `GOPROXY=https://goproxy.cn,direct`、`GOSUMDB=sum.golang.google.cn` |
| Maven | `%USERPROFILE%\.m2\settings.xml` | 阿里云 public，`mirrorOf=central` |
| Gradle | `%USERPROFILE%\.gradle\init.gradle` | 阿里云 public、google、gradle-plugin |
| NuGet | `%APPDATA%\NuGet\NuGet.Config` | 保留 nuget.org，追加华为云 |
| MSYS2 pacman | `C:\Programs\msys64\etc\pacman.conf` | 阿里云、清华 TUNA、中科大 USTC |

策略：

- 有原生命令的用命令：`go env -w`、`pnpm config set`。
- 无原生命令的用模板或受管行。配置存在且内容不同时先备份，`-ForceConfig` 才覆盖；`pacman.conf` 是例外，只增删受管 `Server` 行后直接重写。
- pacman.conf 在 `clangarm64`、`mingw32`、`mingw64`、`ucrt64`、`msys` 每个段头后插入受管 `Server` 行，重复执行只替换受管行。
- PSGallery、VS Code Marketplace 与 winget 无稳定国内镜像，直连。GitHub HTTPS 访问先执行 `scripts\proxy-on.ps1`。
- 下载项声明 `sha256`、`sha512` 或 `hashUrls` 时校验文件哈希，不匹配即终止；未声明的记录告警。
- 归档解压前检查每个条目都落在目标目录内，存在越界条目时终止。

## 配置与 PATH

Config 阶段把 5 条全局要求写入 Codex `%USERPROFILE%\.codex\AGENTS.md`、Claude Code `%USERPROFILE%\.claude\CLAUDE.md` 与 Trae `%USERPROFILE%\.trae-cn\user_rules\`；同目录已有等价规则时跳过，不覆盖用户规则。项目规则仍放在各项目自己的 AGENTS.md。随后写入 Git 全局身份、`init.defaultBranch main` 与 `safe.directory <工作空间根>`；已有 `*` 时只告警，不自动改写。按 `data/user.json` 生成 Claude Code 与 Trae MCP 配置。Claude 配置不包含认证令牌，认证由 CC Switch 注入。

同阶段合并 Windows Terminal 外观：向 `%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json` 的 `profiles.defaults` 写入 Tango Dark、14 号字、49% 透明度、亚克力与 bright 高亮，保留已有 profile、配色方案和其他字段。PowerShell profile 不纳入模板，避免把个人环境变量与密钥复制到新机。

Environment 阶段：

- 机器级 PATH 末段 MSYS2 UCRT64、Maven、Gradle、ARM GNU Toolchain 的 `bin`；机器级 PATH 不写用户目录。
- 用户级 PATH 首位 `%USERPROFILE%\.local\bin`，随后追加 `%APPDATA%\npm`、`%USERPROFILE%\go\bin`、`%USERPROFILE%\.cargo\bin`、`C:\Programs\vcpkg`、Android platform-tools、`%USERPROFILE%\.dotnet\tools`。
- 环境变量：用户 `HOME`、`VCPKG_ROOT=C:\Programs\vcpkg`；机器 `JAVA_HOME`、`CUDA_PATH`（仅 NVIDIA GPU）、`PYTHONUTF8=1`；用户 `GOPATH` 未设置时写入 `%USERPROFILE%\go`。
- 清空 `SSL_CERT_FILE`、`SSL_CERT_DIR`、`CURL_CA_BUNDLE` 的用户级值。
- PATH 通过注册表 `REG_EXPAND_SZ` 直读直写，避免 `setx` 截断；重复执行零写入。

## 人工项

以下项目不自动执行，验收时只列清单：

- TeX Live，清华 TUNA CTAN 镜像。
- TeXstudio，可选，需要时执行 `winget install TeXstudio.TeXstudio`。
- Bambu Studio，可选，需要时执行 `winget install Bambulab.Bambustudio`。
- STM32CubeMX、STM32CubeProgrammer、STM32 ST-LINK Utility。
- STM32CubeCLT，需登录 ST 账号手动下载安装。
- NVIDIA Nsight Systems。
- 火绒安全，官网下载与图形安装器。
- 清单外 Agent Skills，按需从 skills.sh 或插件市场安装。
- `gh auth login`。
- Microsoft 365 激活。
- CC Switch 内的供应商、模型与路由设置。

手动提供的安装包统一放在 `installers/`，该目录内容不纳入版本管理。Snipaste 与 Uninstall Tool 由入口在 System 阶段直接执行；其余文件仅作人工安装备用，入口不会自动安装。

## Agent Skills

`data/skills.json` 是技能白名单，包含来源 `owner/repo@skill`、目录名、方向与用途。`scripts/sync-skills.ps1` 调用 Skills CLI，把缺失项安装到 `%USERPROFILE%\.agents\skills`。

`bootstrap.ps1` 在 Config 阶段默认执行同步，输出写入 `bootstrap.log`，状态写入 `summary.json` 的 `skills` 字段；失败只记录告警，不中断主流程。Verify 阶段会检查清单内技能的 `SKILL.md`，缺失时输出告警。

```powershell
just skills-dry
just skills-sync
just skills-update
just skills-remove
```

离线或受限环境用 `-SkipSkills` 跳过。通用目录由 Codex、Gemini CLI、OpenCode 等直接读取，应用级开关对这些技能不再生效；Claude Code 通过链接使用同一份文件。已存在同名技能时跳过，`-Force` 才重新安装。更新作用于全局已安装技能。清单外技能按需从 https://skills.sh/ 安装。

## 验收

```powershell
just verify
```

等价于 `.\bootstrap.ps1 -Profile Dev -Stages Verify`。检查内容包括：

- `pwsh`、`uv`、`just`、`git`、`gh`、`node`、`npm`、`pnpm`、`gcc`、`g++`、`cmake`、`ninja`、`clangd`、`ccache`、`openocd`、`pyocd`、`ruff`、`pre-commit`、`gitleaks`、`ast-grep`、`delta`、`jq`、`yq`、`rclone`、`ffmpeg`、`code`、`mvn`、`gradle`、`java`、`go`、`rustc`、`cargo`、`dotnet`、`arm-none-eabi-gcc`。
- 有 NVIDIA GPU 时额外检查 `nvcc`，无 GPU 时跳过。
- 工作空间根与八个子目录。
- pip、uv、npm、cargo、Maven、Gradle、NuGet、Go、pacman、Rustup 的镜像配置。
- `PSScriptAnalyzer` 1.25.0+ 与 `Pester` 6.2.0+。

命令缺失或镜像配置不符时退出 1，并逐条列出原因。验收结果写入 `logs/runs/<runId>/environment-report.json`，含平台信息、实际工具版本、失败与告警。

## 回滚

```powershell
.\bootstrap.ps1 -Rollback Last
```

回滚按 manifest 逆序还原配置文件、PATH、环境变量、注册表值与本次新增的 Defender 排除项。已安装软件不卸载。包含机器级变更时同样整体请求 UAC；`-NoElevate` 可跳过提权但只还原用户级变更。

回滚前比对文件当前哈希与本次写入后的哈希。文件在运行后被修改或删除时保留现状，记为冲突并跳过该项。
